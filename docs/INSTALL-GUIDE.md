# Daylight Office 설치 안내 (가족용)

이 프로그램은 **코드 서명이 없습니다**(인증서 비용 때문에 정한 사항, 2026-11-17). 그래서 처음 실행할 때 Windows 가 경고를 띄울 수 있습니다. 아래대로 하면 됩니다.

## 설치
1. 받은 `Daylight-Setup-<버전>.exe` 를 두 번 누릅니다.
2. 파란 화면 **"Windows 의 PC 보호"** 가 뜨면 **추가 정보** 를 누르고 **실행** 을 누릅니다.
3. 안내에 따라 **다음** 을 누릅니다. 관리자 암호는 필요 없습니다(내 계정에만 설치).
4. "docx, xlsx ... 열기 프로그램에 추가" 는 원하면 체크합니다. 체크해도 기본 프로그램이 바뀌지는 않습니다. 파일을 우클릭 → **연결 프로그램** 에서 고르세요.

## 실행이 아예 막히는 경우
"스마트 앱 컨트롤" 이 켜져 있으면 서명 없는 프로그램이 막힙니다. 설정 → 개인 정보 및 보안 → Windows 보안 → 앱 및 브라우저 컨트롤 → 스마트 앱 컨트롤 에서 확인합니다. (한 번 끄면 다시 켤 수 없는 PC 도 있으니, 관리하는 사람에게 먼저 물어보세요.)

## 업데이트
자동 업데이트는 없습니다. 새 설치 파일을 같은 방법으로 설치하면 위에 덮어 설치되고, 문서와 설정은 그대로입니다.

## 제거
설정 → 앱 → Daylight Office → 제거. 설정 폴더(`%LOCALAPPDATA%\Daylight`)는 남습니다.

## 설치 파일이 믿을 만한지 확인
같이 받은 `SHA256SUMS.txt` 의 값과 아래 명령 결과가 같으면 됩니다.
```
certutil -hashfile Daylight-Setup-<버전>.exe SHA256
```
