# M4 정보 구조 초안 (2026-11-17, 사용자 승인 대기)

화면 근거: `docs/shots/m4-tour-word.png`, `m4-tour-cell.png`. 기준 사양은 옛 저장소의 `docs/UX-DESIGN.md`(`git -C .. show HEAD:docs/UX-DESIGN.md`) 3절(P0/P1). 숨김은 `patches/web-apps/0001` 의 `_daylightHidden` 목록(탭 단위 id)과, 더 잘게 숨길 때는 테마 CSS 주입(`tools/theme`)으로 한다.

## 이번에 적용한 것
| 숨김 | 이유 |
|---|---|
| 그리기 탭(`toolbar-draw`) | 펜 전용, 가족 사용 적음(M1에서 적용) |
| 보호 탭(`toolbar-protect`) | 암호화·전자 서명·문서 보호는 전문가용. 암호 저장은 파일 메뉴에 남음 |
| 플러그인 탭(`toolbar-plugins`) | 외부 플러그인 설치 진입점, 오프라인 방침과 맞지 않음 |

## 현재 탭 구성
- 문서: 홈 · 삽입 · 레이아웃 · 참조 · 협업 · 보기
- 표: 홈 · 삽입 · 레이아웃 · 수식 · 데이터 · 협업 · 보기
- 슬라이드: 홈 · 삽입 · 디자인 · 전환 · 애니메이션 · 협업 · 보기

## 판단이 필요한 후보(숨길까요?)
| 후보 | 위치 | 제안 |
|---|---|---|
| 협업 탭의 비교/결합, 표시 모드 | 문서 | 유지(편지 검토에 쓸 수 있음) — 그러나 "협업" 이름은 "검토"로 바꾸는 것을 제안 |
| 참조 탭(목차·각주·상호 참조) | 문서 | 유지(P1), 가끔 쓰는 기능 |
| 표 > 수식 탭의 추적/감시창/계산 옵션 | 표 | 유지, 전문가 기능은 그룹 단위로 접기 검토 |
| 표 > 데이터 탭의 목표값·해 찾기·외부 링크 | 표 | 숨김 후보 |
| 삽입 > 컨텐츠 컨트롤, 필드, 수식 편집기 | 문서 | 컨텐츠 컨트롤·필드 숨김 후보 |
| 보기 > 매크로 | 공통 | 숨김 후보(보안) |
| 상태줄 언어 표시 | 공통 | 유지 |
| 홈 도구줄의 버튼 크기 28~34px | 공통 | 별도 CSS 로 키우기(시각 확인 필요) |
